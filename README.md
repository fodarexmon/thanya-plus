# ثانية+ V4 — React

منصة React (Vite) للصف الثاني الإعدادي في مصر، الترم الأول 2026/2027.

## سياسة الفيديو
- كل الشروح **تعمل داخل المنصة** (YouTube embed)، ولا توجد روابط تنقلك خارج الموقع.
- حتى 5 شروح لكل درس. الأولوية لـ 2026/2027، ثم 2025/2026 لنفس المحتوى، مع إظهار السنة وعنوان الفيديو.
- **العلوم:** مس شيماء أيوباك والقزاز (مستر أمجد القزاز 2026/2027، ومستر مصطفى القزاز 2025/2026 لنفس المنهج الجديد) يظهران أولًا. وإذا لم يُنشر شرح لدرس بعد، تظهر بطاقة «قريبًا».

## التشغيل
```bash
npm install
npm run dev
```

## تحديث الفيديوهات
```bash
node scripts/resolve.mjs        # يبحث عن فيديوهات مطابقة لكل درس -> src/data/resolved.json
node scripts/verify-embed.mjs   # يحذف أي فيديو يمنع صاحبه التضمين
```

## النشر
```bash
npm run build   # ثم ارفع مجلد dist (أو اربط المشروع بـ Vercel)
```
